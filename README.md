# DTEN Ethical Hacking Essentials Internship

This repository contains my practical work and documentation completed during the **Ethical Hacking Essentials Internship** with **Daryl Tech & Educational Network (DTEN)**.

The internship focused on practical cybersecurity concepts including reconnaissance, vulnerability assessment, web application security testing, exploitation in controlled laboratory environments, and Capture The Flag (CTF) challenges.

## About the Internship

The programme provided hands-on experience with common cybersecurity tools and techniques through intentionally vulnerable laboratory environments and beginner-friendly security challenges.

All security testing documented in this repository was conducted in authorized lab environments for educational and defensive cybersecurity purposes.

## Internship Tasks

### Task 1 — Reconnaissance & Footprinting

Conducted reconnaissance and service enumeration against a controlled laboratory target.

**Key activities:**

* Network reconnaissance
* Port and service enumeration
* Service/version identification
* Web application identification
* Security observations and documentation

**Tools used:**

* Kali Linux
* Nmap
* VirtualBox
